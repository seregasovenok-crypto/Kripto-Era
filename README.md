# Крипто эра

Бот для Telegram-канала «Крипто эра»: отобранные крипто-новости и сводка курсов.

## Что публикуется
- **Новости** (`post_news.py`): каждые 2 часа с 8:00 до 22:00 МСК по одной самой свежей новости, итого ~8 в день.
  Источники: ForkLog, Bits.media, BeInCrypto (рус.), CoinDesk, Cointelegraph, Decrypt (с переводом).
  Дубли с похожими заголовками отсеиваются, источники чередуются, хэштеги ставятся автоматически.
- **Курсы** (`prices.py`): в 9:00 и 21:00 МСК курсы BTC, ETH, SOL, BNB, XRP, TON, DOGE и индекс страха и жадности.

## Запуск
1. Создать бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопировать токен.
2. Создать публичный канал и добавить бота администратором с правом публикации.
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN`: токен бота;
   - `TELEGRAM_CHANNEL`: `@имя_канала`.
4. **Actions** → включить workflows → запустить «Новости» и «Сводка курсов» вручную (Run workflow).
   Первый запуск новостей только запоминает текущие статьи и ничего не публикует, второй уже постит.

## Настройка
- Частота новостей: `cron` в `.github/workflows/news.yml`, постов за запуск: `MAX_POSTS_PER_RUN` в `post_news.py`.
- Источники: список `FEEDS`, хэштеги: список `HASHTAGS` в `post_news.py`.
- Монеты в сводке: список `COINS` в `prices.py`.

## Видео для TikTok / Reels / Shorts
`video.py` каждый день в 20:30 МСК собирает вертикальный ролик (1080×1920, ~45–60 с) из 3 главных новостей дня:
1. **Новости**: последние опубликованные в канале (их запоминает `post_news.py`), при нехватке добираются из ForkLog, Bits.media, BeInCrypto.
2. **Сценарий**: интро-«крючок» → новости (заголовок + 1–2 предложения) → призыв подписаться на Telegram.
3. **Озвучка**: бесплатный нейроголос `ru-RU-DmitryNeural` (edge-tts), запасной вариант gTTS.
4. **Картинки**: рисуются кодом под тему новости (BTC, ETH, TON, взлом, регулирование, ETF, рост/падение рынка), без чужих фото и логотипов, поэтому проблем с авторскими правами нет.
5. **Субтитры**: крупные, по 2–4 слова, синхронно с голосом.
6. **Сборка**: ffmpeg, лёгкий зум фона, переходы.
7. **Доставка**: ролик и готовое описание с хэштегами приходят в личку от бота. Последний ролик всегда лежит в ветке `videos` (`latest.mp4` → «Download raw file»).

Публикация в TikTok вручную: скачать ролик из Telegram → TikTok «+» → загрузить → вставить описание.
(Автопостинг через API TikTok требует одобренного приложения разработчика, это отдельный шаг.)

Настройка: добавить секрет `TELEGRAM_VIDEO_CHAT` с твоим числовым chat id (написать боту `/start`,
затем открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`).
Голос, число новостей и т.д.: переменные `VIDEO_VOICE`, `VIDEO_NEWS`, `VIDEO_VOICE_RATE` в `video.py`.
Запуск вручную: Actions → «Видео для TikTok» → Run workflow.
