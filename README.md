# Крипто эра

Бот для Telegram-канала «Крипто эра»: отобранные крипто-новости и сводка курсов.

## Что публикуется
- **Новости** (`post_news.py`): каждые 2 часа с 8:00 до 22:00 МСК по одной самой свежей новости, итого ~8 в день.
  Источники: ForkLog, Bits.media, BeInCrypto (рус.), CoinDesk, Cointelegraph, Decrypt (с переводом).
  Дубли с похожими заголовками отсеиваются, источники чередуются, хэштеги ставятся автоматически.
- **Курсы** (`prices.py`): в 9:00 и 21:00 МСК курсы BTC, ETH, SOL, BNB, XRP, TON, DOGE и индекс страха и жадности.

## Запуск
1. Создать бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопировать токен.
2. Создать публичный канал и добавить бота администратором с правом публикации.
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN`: токен бота;
   - `TELEGRAM_CHANNEL`: `@имя_канала`.
4. **Actions** → включить workflows → запустить «Новости» и «Сводка курсов» вручную (Run workflow).
   Первый запуск новостей только запоминает текущие статьи и ничего не публикует, второй уже постит.

## Настройка
- Частота новостей: `cron` в `.github/workflows/news.yml`, постов за запуск: `MAX_POSTS_PER_RUN` в `post_news.py`.
- Источники: список `FEEDS`, хэштеги: список `HASHTAGS` в `post_news.py`.
- Монеты в сводке: список `COINS` в `prices.py`.

Материалы для оформления и монетизации канала: [docs/channel-kit.md](docs/channel-kit.md).
